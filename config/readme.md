## /config?, funciones y necesidades de este directorio

*¿por que no tener todo en una sola carpeta en lugar de todo repartido?*, una pregunta que puede surgir y es completamente normal.

en suriaX una de las principales preocupaciones es tener **codigo ilegible**, **imposible de mantener** o **ineficiente**, gracias a esto se podra ver que existen grandes cantidades de directorios y archivos, esto asegura que, tanto el desarrollador principal como los futuros contribuidores no se centren en un solo archivo o incluso algunas refactorizaciones / cambios demoren dias o semanas.

*happy coding : )*
