
# Contributing

suriaX is currently developed by a single maintainer and is **not accepting
external contributions** (PRs, issues asking for feature work, etc.) at this
stage of the project.

This will change once the language and its two companion projects, [iriscX](https://github.com/samue1-pineda/iriscx) (traits) and[myrscX](https://github.com/samue1-pineda/MyrscX) (region-based memory management), reach a more stable point.

If you find a bug, feel free to open an issue describing it — reports are
welcome even while contributions are closed.
